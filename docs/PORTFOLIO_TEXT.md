# Portfolio project title

**AI-Powered Customer Purchase Prediction System | Flask MVC & Machine Learning**

## Short portfolio description
Developed an end-to-end customer purchase prediction web application using Python, Flask, Scikit-learn, and SQLite. Built a Random Forest classification pipeline, integrated real-time predictions into a Flask MVC-style architecture, and implemented a responsive dashboard with prediction history.

## Resume bullet
- Built a Flask-based ML web application using a Random Forest classifier to estimate customer purchase likelihood, including data generation, model evaluation, input validation, and SQLite prediction-history storage.

## Suggested skills
Python, Flask, MVC Architecture, Machine Learning, Random Forest, Classification, Pandas, NumPy, Scikit-learn, SQLite, HTML, CSS, JavaScript, Model Deployment.
